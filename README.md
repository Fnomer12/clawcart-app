# clawcart-ai-shopping-assistant
ClawCart is a modern AI-powered shopping assistant designed to help users quickly discover the best products based on their preferences, budget, and requirements. Instead of manually comparing dozens of items online, users simply describe what they are looking for, and ClawCart intelligently analyzes the request to suggest and rank the best options.

The application features a clean ChatGPT-style interface with a sidebar that keeps track of previous searches, allowing users to easily revisit past queries. Users can sign in with their email or Google account, manage their profile settings, change language preferences, and switch between light and dark themes.

Built using Flutter and Firebase, ClawCart focuses on delivering a fast, intuitive, and scalable mobile experience while demonstrating modern mobile architecture and UI design principles.

Key Features
	•	AI-powered product search and comparison
	•	Firebase Authentication (Email & Google Sign-In)
	•	ChatGPT-style interface with search history sidebar
	•	Multi-language support (English, French, Spanish)
	•	Dark / Light theme switching
	•	User profile and settings management
	•	Built with Flutter and Firebase

Tech Stack
	•	Flutter
	•	Firebase Authentication
	•	Cloud Firestore
	•	Provider (state management)
	•	Material UI
